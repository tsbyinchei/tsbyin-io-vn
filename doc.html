Tài liệu tsbyin.io.vn

Hướng dẫn toàn diện về quy trình cấp phát, quy định kỹ thuật và cấu hình DNS cho subdomain.

01 // Quy trình đăng ký 4 bước

  1. Fork repository: Truy cập repo github.com/tsbyinchei/tsbyin-io-vn và bấm Fork về tài khoản của bạn.
  2. Tạo file cấu hình: Thêm file domains/<tên-subdomain>.json. Bạn có thể sử dụng công cụ tạo JSON tại trang chủ để tạo sẵn file chuẩn xác.
  3. Mở Pull Request (PR): Tạo PR từ nhánh của bạn vào nhánh main. GitHub Actions (pr-check.yml) sẽ chạy tự động trong khoảng 15 giây.
  4. Tự động đồng bộ: Khi PR được merge, GitHub Actions (deploy-dns.yml) sẽ gọi Cloudflare API để tạo bản ghi DNS ngay lập tức.

02 // Mẫu cấu hình các nền tảng phổ biến

1. Trỏ về GitHub Pages:

{
  "owner": {
    "github": "tsbyinchei",
    "email": "you@domain.dev"
  },
  "records": [
    {
      "type": "CNAME",
      "name": "@",
      "value": "tsbyinchei.github.io",
      "proxied": false
    }
  ]
}

2. Trỏ về Vercel:

{
  "owner": { "github": "your-username", "email": "you@domain.dev" },
  "records": [
    {
      "type": "CNAME",
      "name": "@",
      "value": "cname.vercel-dns.com",
      "proxied": false
    }
  ]
}

3. Trỏ về máy chủ VPS cá nhân (IPv4 & Subdomain con):

{
  "owner": { "github": "your-username", "email": "you@domain.dev" },
  "records": [
    { "type": "A", "name": "@", "value": "123.45.67.89", "proxied": true },
    { "type": "A", "name": "api", "value": "123.45.67.89", "proxied": true }
  ]
}

03 // Tiêu chuẩn an toàn & Bảo mật

  • Subdomain hợp lệ: Dài từ 3 đến 32 ký tự, chỉ gồm chữ thường a-z, chữ số 0-9 và dấu -.
  • Chặn SSRF / Private IP: Không chấp nhận trỏ bản ghi A/AAAA về IP nội bộ (127.0.0.1, 10.0.0.0/8, 192.168.0.0/16, 172.16.0.0/12).
  • Chặn CNAME Tunnel: Chặn trỏ CNAME về .trycloudflare.com, .cfargotunnel.com, .workers.dev, .r2.dev, .blob.core.windows.net, .ts.net.
  • Bảo vệ quyền sở hữu: Chỉ tài khoản GitHub khai báo trong owner.github mới có quyền sửa hoặc xóa file của chính mình.
